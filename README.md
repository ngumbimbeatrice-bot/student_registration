# Student Registration System

## Project Overview
The Student Registration System is a web-based application developed using PHP. It is designed to demonstrate student registration and information management through web technologies.

## Technologies Used
- PHP – Backend development
- HTML – Web page structure
- CSS – Styling
- MySQL – Database management (if implemented)
- XAMPP – Local development server
- Visual Studio Code – Code editor
- Git – Version control
- GitHub – Source code hosting

## Development Environment
The project was developed locally using XAMPP and Visual Studio Code.

## How to Run the Project
1. Install XAMPP.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache from the XAMPP Control Panel.
4. Open your browser.
5. Visit `http://localhost/student_registration/`.

## Project Status
Developed as a practical PHP web development project.
